Light Table

A private review tool for video and design production, run by Eyal Fabregat.

Light Table lists the creative work assigned to its operator in the project-management tools the production team already uses. It shows each piece next to its brief and review notes, and keeps the work moving from brief to approval.

What it does with Google Drive

  • Reads the briefs, footage and reference files that a task links to, so the work can be prepared.
  • Uploads finished deliverables to the Drive folder that a task points to, when a piece is approved for review.

It touches only the files and folders needed for that work, and only after the operator signs in with Google.

Light Table is not a public service and has no sign-up. It runs on its operator's own computer for his production work.
