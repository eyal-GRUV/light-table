Privacy policy

Last updated: 12 October 2026

Light Table is a private creative-review tool run by Eyal Fabregat ("we") for his own video and design production work. This policy explains what data Light Table accesses, how it is used, and how it is protected.

Who uses Light Table

Light Table has no public sign-up. Only its operator signs in with Google, and only to connect the Google Drive account used for production work.

Google user data we access

  • Google Drive files and folders that production tasks link to: briefs, footage, reference images and earlier deliveries. Light Table lists and downloads them so the work can be prepared.
  • Drive folders for deliveries. Finished files are uploaded there when a piece is approved for review, and their links are returned to the task.
  • The signed-in account's email address, to show which Drive account is connected.

How we use it

  • Only to prepare, review and deliver the creative work that the operator is producing.
  • We do not sell Google user data, use it for advertising, or transfer it to anyone else, except where the operator's own production tools need a delivery link.
  • We do not use Google user data to develop, improve or train generalized artificial-intelligence or machine-learning models.

Light Table's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

Sign-in tokens and working copies of files stay on the operator's own computer, in a folder only that computer's user account can read. They are not stored on any shared server. Files are fetched over encrypted connections (HTTPS).

Retention and deletion

Working copies are kept only as long as the production work needs them. The operator can disconnect Light Table at any time from the Google Account's third-party access page. That revokes its access, and its stored sign-in token stops working.

Other information

Light Table also reads task details and comments from the project-management tools the production team uses, only to show the work and its review notes to the operator.

Changes

If this policy changes, the date above is updated.
